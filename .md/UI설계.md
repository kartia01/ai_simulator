# ClickMe UI 설계

| 버전 | v1.1 |
|---|---|
| 작성일 | 2026-06-08 |
| 참고 | clickme_ui.pptx |

> **참고사항 (PPTX Slide 1)**
> - 이 문서는 ClickMe 서비스의 UI 구조를 제시하는 설계 문서다
> - 모든 페이지는 디자인의 스타일을 맞춰서 제작한다
> - 시뮬레이터 페이지, 분석 페이지 등의 파라미터는 개발 과정 중에 자주 변동될 수 있다
> - 각 섹션에서 제목만 있고 구체적인 레이아웃이 없는 경우, 다른 페이지의 스타일을 참고하여 제작한다

---

## 1. 페이지 흐름

```
진입 페이지
    │
    └── [로그인] 버튼 클릭
            │
        로그인 페이지 (Phase 1: 역할 선택)
            ├── [관리자로 진입] → 관리자 페이지 (/admin)
            └── [사용자로 진입] → 채팅창 (/)
                                    │
                    ┌───────────────┼───────────────┐
                    │               │               │
                관리자 페이지    시뮬레이터       대시보드
                  /admin         /simulator      /dashboard
                    │
                  각종 관리 페이지
                  /admin/users, /admin/chats
```

---

## 2. 글로벌 공통 요소

모든 페이지에 적용되는 공통 UI:

| 위치 | 요소 | 동작 |
|---|---|---|
| 좌측 상단 | 서비스 로고 | 클릭 시 진입 페이지(`/landing`)로 이동 |
| 우측 상단 | 테마 토글 | 다크/라이트 모드 전환 |
| 우측 상단 | 역할 배지 (채팅창 이후) | 현재 역할 표시 (Admin / User) |

---

## 3. 진입 페이지 (`/landing`)

**목적**: 서비스 소개 및 정보 제공. 로그인 유도.

### 레이아웃

```
┌─────────────────────────────────────────────┐
│ [로고]                            [로그인 →] │
├─────────────────────────────────────────────┤
│                                             │
│         ClickMe                             │
│    AI 광고 효과 분석 플랫폼                    │
│                                             │
│    광고를 업로드하면 AI가 소비자 반응을         │
│    시뮬레이션하고 성과를 예측합니다             │
│                                             │
│         [무료로 시작하기 →]                   │
│                                             │
├─────────────────────────────────────────────┤
│  핵심 기능 소개                               │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐    │
│  │ 시뮬레이션 │ │ 페르소나  │ │ 성과 예측 │    │
│  └──────────┘ └──────────┘ └──────────┘    │
├─────────────────────────────────────────────┤
│  고객 문의: support@clickme.io  (mailto:)    │
└─────────────────────────────────────────────┘
```

### 주요 요소
- 상단: 서비스 로고(좌) + 로그인 버튼(우)
- 히어로 섹션: 서비스 소개 문구 + CTA 버튼
- 기능 소개 카드 (시뮬레이션, 페르소나, 성과 예측)
- 고객 문의: `mailto:` 링크 (실제 인앱 폼 없음)

## 4. 로그인 페이지 (`/login`)

**목적**: Phase 1 — 역할 선택 후 즉시 진입 (실제 인증 없음)

### Phase 1 레이아웃

## 5. 채팅창 — 메인 페이지 (`/`)

**목적**: AI 어시스턴트와 대화. 시뮬레이션 결과 열람. 주요 기능 진입점.

### 레이아웃

```
┌─────────────────────────────────────────────────────────┐
│ [로고]    [시뮬레이터] [대시보드] [관리자/사용자 페이지]  │
├─────────────────┬───────────────────────────────────────┤
│  채팅 세션 목록  │  채팅 영역                            │
│                 │                                       │
│  + 새 채팅      │  ┌───────────────────────────────┐    │
│  ─────────      │  │  AI: 안녕하세요! 광고를 분석하  │    │
│  ○ 세션 1       │  │  거나 시뮬레이션 결과를 확인할  │    │
│  ○ 세션 2       │  │  수 있습니다.                  │    │
│  ○ 세션 3       │  └───────────────────────────────┘    │
│  ...            │                                       │
│                 │  [시뮬레이션 결과 스트리밍 영역]        │
│                 │                                       │
│                 ├───────────────────────────────────────┤
│                 │  [메시지 입력창]         [전송 ▶]      │
└─────────────────┴───────────────────────────────────────┘
```

### 우측 상단 네비게이션 버튼
- **관리자/사용자 페이지**: 역할에 따라 `/admin` 또는 `/settings`로 이동
- **시뮬레이터**: `/simulator`로 이동
- **대시보드**: `/dashboard`로 이동

### 사이드바
- 새 채팅 생성 버튼
- 이전 채팅 세션 목록 (클릭 시 해당 세션으로 이동)

## 6. 광고 시뮬레이터 (`/simulator`)

**목적**: 광고 업로드 및 시뮬레이션 실행. 실시간 진행률 표시. 결과 확인.

### Step 1: 광고 입력

```
┌─────────────────────────────────────────────┐
│  광고 시뮬레이터                              │
│                                             │
│  광고 유형 선택                               │
│  ○ 이미지   ○ 텍스트   ○ 영상 [Phase 2]     │
│                                             │
│  ─── 이미지 선택 시 ───                       │
│  ┌─────────────────────────────────────┐    │
│  │                                     │    │
│  │     여기에 파일을 드롭하거나           │    │
│  │     [파일 선택] 버튼을 클릭하세요      │    │
│  │     (JPG, PNG, WebP, GIF / 최대 10MB)│    │
│  └─────────────────────────────────────┘    │
│                                             │
│  ─── 텍스트 선택 시 ───                       │
│  헤드라인  [___________________________]     │
│  본문      [___________________________]     │
│  CTA 문구  [___________________________]     │
│                                             │
│  페르소나 수: [20 ▾]  목적: [전환율 ▾]        │
│                                             │
│  [시뮬레이션 시작]                           │
└─────────────────────────────────────────────┘
```

### Step 2: 시뮬레이션 진행 (SSE)

```
┌─────────────────────────────────────────────┐
│  시뮬레이션 진행 중...                        │
│                                             │
│  ✅ Stage 1: 광고 분석 완료 (1.2초)           │
│  ✅ Stage 2: 페르소나 20명 생성 완료 (3.4초)  │
│  ⏳ Stage 3: 반응 시뮬레이션 중...           │
│     ████████░░░░░░░░  5 / 20 (25%)          │
│  ○ Stage 4: 결과 집계 대기                   │
│  ○ Stage 5: 성과 예측 대기                   │
│  ○ Stage 6: 개선안 생성 대기                 │
│                                             │
│  예상 완료: ~30초                            │
└─────────────────────────────────────────────┘
```

### Step 3: 결과 화면

```
┌─────────────────────────────────────────────────────────┐
│  시뮬레이션 결과                     [PDF 다운로드 ↓]    │
├──────────────────┬──────────────────────────────────────┤
│  KPI 요약        │  채팅창 스트리밍 결과                  │
│                  │                                      │
│  CTR  42%        │  AI: 이번 광고 분석 결과를 말씀드립니다│
│  CVR  18%        │  CTR 예측값은 42%로...               │
│  신뢰도 0.87     │                                      │
│                  │  [추가 질문 입력]          [전송 ▶]   │
├──────────────────┴──────────────────────────────────────┤
│  펀넬 차트                                              │
│  주목(78%) → 이해(65%) → 클릭(42%) → 전환(18%)          │
├─────────────────────────────────────────────────────────┤
│  세그먼트별 반응                                         │
│  [차트: 연령대별 / 성별별 / 소득별]                       │
├─────────────────────────────────────────────────────────┤
│  개선안                                                 │
│  🔴 HIGH: CTA 문구가 너무 모호함 → "지금 구매하기"로 변경│
│  🟡 MEDIUM: 색상 대비 부족 → ...                        │
└─────────────────────────────────────────────────────────┘

* 이 결과는 AI 시뮬레이션 기반 예측치로, 실제 결과와 다를 수 있습니다.
```

## 8. 관리자 페이지 (`/admin`)

**목적**: 전체 사용자 및 시스템 통계 관리. Admin 역할만 접근 가능.

```
┌─────────────────────────────────────────────────────────┐
│  관리자 대시보드                                          │
├──────────────────────┬──────────────────────────────────┤
│  사이드바            │  메인 영역                         │
│                      │                                  │
│  ○ 대시보드          │  전체 통계                         │
│  ○ 회원 관리         │  ┌─────┐ ┌─────┐ ┌─────┐         │
│  ○ 채팅 기록         │  │ 사용자│ │시뮬  │ │비용  │         │
│                      │  │  42 │ │318건 │ │$12  │         │
│                      │  └─────┘ └─────┘ └─────┘         │
│                      │                                  │
│                      │  회원 관리 (/admin/users)          │
│                      │  채팅 기록 (/admin/chats)          │
└──────────────────────┴──────────────────────────────────┘
```

## 9. 사이드바 네비게이션 (로그인 후 공통)

```
사용자 모드:
├── 채팅창 (/)
├── 시뮬레이터 (/simulator)
├── 프로젝트 (/projects)
├── 광고 내역 (/ads)
├── 대시보드 (/dashboard)
├── 리포트 (/reports)
├── 설정 (/settings)
└── [Phase 2] 광고 생성 (/generate), 보관함 (/storage)

관리자 모드 (추가):
└── 관리자 (/admin)
    ├── 회원 관리 (/admin/users)
    └── 채팅 기록 (/admin/chats)
```

## 10. 디자인 원칙

| 원칙 | 내용 |
|---|---|
| 다크/라이트 모드 | 헤더에서 토글. 시스템 전체 적용 |
| 폰트 | 한국어 최적화. 가독성 우선 |
| 색상 | 브랜드 색상 일관성. 접근성(대비비) 준수 |
| 반응형 | 데스크탑 우선. 모바일은 고려사항 |
| 로딩 상태 | 시뮬레이션 진행 중 SSE 진행률 명확 표시 |
| 면책 문구 | 시뮬레이션 결과 화면 하단에 항상 표시 |
