## 1. 프로젝트 개요

**ClickMe**는 광고를 업로드하면 AI가 가상 소비자 페르소나의 반응을 시뮬레이션하고, CTR·CVR 등 성과를 예측하여 개선안까지 제공하는 **광고 효과 분석 플랫폼**이다.

기존의 "광고 분석"과 "광고 시뮬레이터" 두 기능을 **시뮬레이션** 하나로 통합하였다. 페르소나 생성도 시뮬레이션 파이프라인에 포함된다.

---

## 2. 핵심 기능

### 2-1. 시뮬레이션 (핵심)

광고 입력 → 6단계 AI 파이프라인 → 성과 예측 + 개선안 출력

| Stage | 기능 |
|---|---|
| Stage 1 | 광고 분석 (이미지/텍스트/영상 구성 요소 추출) |
| Stage 2 | 페르소나 생성 (가상 소비자 20명, 3계층 속성) |
| Stage 3 | 반응 시뮬레이션 (페르소나별 클릭 의향, 감성, 주목도 등) |
| Stage 4 | 결과 집계 (이상치 제거, 세그먼트별 통계) |
| Stage 5 | 성과 예측 (CTR, CVR, Trust Score 등 KPI) |
| Stage 6 | 개선안 생성 (카피 수정, CTA 제안, 타깃별 권고) |

### 2-2. AI 채팅 어시스턴트

- 광고 관련 자유 질문 응답 (Claude Sonnet)
- 시뮬레이션 결과를 컨텍스트로 활용
- 이전 채팅 기록 저장 및 조회

### 2-3. 광고 생성 (Phase 2, 7/8 목표)

- 이미지 생성: GPT Image 2
- 영상 생성: Gemini Omni

## 3. 기술 스택

| 레이어 | 기술 |
|---|---|
| **Frontend** | Next.js 15 (App Router), React 19, TypeScript |
| | Zustand (상태 관리), TanStack Query (서버 상태) |
| **Backend** | FastAPI, Uvicorn, Pydantic v2, SQLAlchemy Async |
| | Background Worker → ECS Fargate Worker (향후) |
| **AI** | LangChain, LangGraph, LangSmith |
| **LLM** | GPT-4o Vision, GPT-4o-mini, Claude Haiku, Claude Sonnet |
| | GPT Image 2 (이미지 생성), Gemini Omni (영상 생성, Phase 2) |
| **Database** | NeonDB (PostgreSQL 16 + pgvector) |
| **Cloud** | AWS S3 (파일 저장), AWS SQS (비동기 큐, Phase 2) |
| **Auth** | Phase 1: UI 역할 선택만 / Phase 2: OAuth2 + JWT (미정) |
| **Infra** | Docker, uv, GitHub Actions |
| **Communication** | SSE (Server-Sent Events) |

**고려 중 (선택사항):**
- Alembic: SQLAlchemy Async와 용도가 다름. 마이그레이션 관리 필요 시 도입
- Redis: SQS+SSE+PostgreSQL로 커버 가능. 초당 요청 급증, 동일 결과 반복 요청, 실시간 공유 상태 복잡해질 경우 도입

**향후 도입 예정:**
- Background Worker → ECS Fargate Worker (스케일 아웃 시)
- Embedding Model (RAG 고도화 시)

## 5. 팀 개발 구조

시뮬레이션을 6명이 각자 독립적으로 연구·개발한다.

- 각 팀원은 시뮬레이션의 특정 Stage를 맡아 독립적으로 구현
- 공통 Input/Output 계약(Contract, Pydantic 스키마)을 먼저 확정한 후 개발
- 통합 파이프라인(LangGraph)에서 각 Stage 구현체를 연결
- 동일 Stage에 여러 구현체를 넣어 LangSmith로 비교·분석 가능

> 팀원 구성은 변동이 많으므로 본 문서에 기재하지 않는다.
